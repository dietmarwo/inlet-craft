inlet-craft

Rust library and tools for an aerosol inlet, sampling line, mixing volume and sensor on a moving platform. It evaluates published correlations with SI inputs and explicit validity diagnostics, then searches designs with fcmaes DE or MODE.

Status: provisional 0.1.0 source candidate. Software verification is included; the stronger original-source/published-point gate G0 and independent comparison gate G1 remain incomplete. No on-bike validation, release tag or package publication is claimed. Start with the guide and the evidence ledger.

First evaluation

Rust 1.88 or later and a Cargo registry connection on the first build. The two ecosystem crates are pinned source snapshots in vendor/, with upstream revisions and MIT licenses. Cargo registry dependencies are locked, not vendored.

cargo build --release --locked
target/release/inlet-craft check examples/bicycle.json > target/check.json
target/release/inlet-craft evaluate examples/bicycle.json > target/bicycle.json
target/release/inlet-craft verify > target/verification.json

The bicycle example has four riding speeds, two crosswinds and a declared bimodal number distribution. Aspiration can exceed one. Tube transport should be at most one inside its valid range; outside-range extrapolation is returned with diagnostics and is never clipped.

Interpretation

For sub-micron particles in the facing, sub-isokinetic scenarios, the Liu transmission correlation is evaluated below its fitted Stokes range and returns values slightly above one. The evaluator keeps those values unclipped and reports, per size and per PM cut, how much of the result rests on them (nonphysical_transport_excess, nonphysical_excess). For the bicycle study that share is of order 1e-4 to 1e-3 of the PM10 mass, two orders below the 15% tolerance, so the study accepts it explicitly. Without the allowance (strict-nonphysical-guard) every full-distribution candidate is rejected, as in the 0.1.0 candidate. Neither outcome says anything about built hardware.

The coarse monodisperse sensitivity tests a different declared aerosol; it demonstrates search behaviour and conditional tradeoffs only, and is not a recommended bike design. The deliberately impossible zero-resolution goal tests truthful finite-search failure reporting.

Architecture

The workspace has three first-party crates. inlet-craft owns SI primitives, strict models, literature equations, diagnostics, compositional evaluation, response, evidence fixtures and design search. inlet-craft-cli owns JSON command dispatch and the separate actual SDK worker binary. inlet-craft-py is a PyO3 JSON bridge with a small dict wrapper. The core and executables forbid unsafe Rust; external dependencies are not covered by that first-party attribute.

Input validation precedes physics. The aerodynamic/physical conversion is implicit because Cunningham slip depends on diameter. The evaluator resolves apparent wind and inlet orientation, computes aspiration separately from transmission, then multiplies transport mechanisms. Each requested size has an element breakdown; distribution quadrature uses the same path and aggregates diagnostic ranges. Buffers/splits are explicit assumptions rather than hidden empirical formulas.

Response is independent of particle size and computed once per case. One/two first-order stages use analytic formulas, repeated poles have a stable equal-tank limit, and longer chains use phase-type uniformization with preflight work caps. Plug delay and the trailing average are added to the response. All public JSON includes precise engineering definitions of mean age/resolution.

The search wrapper mutates only declared design fields, validates every candidate, and calls actual fcmaes DE or MODE. MODE uses 3 objectives and 1 aggregate violation. The solver's state cannot alter the evaluator. Returned points are rebuilt and evaluated cold, then constraint-checked again. Invalid rows remain evidence, bounded in the compact search JSON. Walltime/cancellation are checked between objectives and before each cold recheck; a runner provides hard process limits.

Versioned case/result/study/search/verification schemas are generated from Rust types with schemars. describe embeds the formula catalog and complete provenance ledger. scripts/check_docs.py checks generated artifacts and executes authored code fences. A static documentation site is generated for hosting; nothing is deployed automatically.

The two ecosystem dependencies are source snapshots from upstream HEAD retrieved on 2026-11-14, recorded in each vendor/*/VENDORED.md. Their algorithm code is unchanged; only fcmaes workspace-inherited Cargo metadata is made standalone. This makes the source ZIP independent of later ecosystem git changes. Third-party registry crates still come from Cargo with the lockfile.

Numerical resource limits include 512 scenarios, 256 requested diameters, 100 elements, 8 modes, 16–256 quadrature bins, and a 2 million scenario/particle/element work estimate. The response solver has a separate cap. These bounds prevent accidental unbounded allocations or stiff-chain hangs; they are computational support limits, not experimentally established aerosol limits.

Outstanding scientific work is listed in the evidence ledger and validation protocol. The architecture deliberately leaves room for verified alternative correlations; it does not silently replace missing physics with fitted constants.

Conflicts resolved and uncovered parts

The B lecture gives a wider Belyaev range (.005–10, .2–5) than W; use W's narrower St range and retain diagnostics. B's Gormley–Kennedy diffusion is an independent alternative, not the chosen Holman formula. Bend angle uses radians (a 90deg bend at St=.171 has .5 penetration, not almost zero). Contraction St does not use downstream velocity. Calm St does not use wind speed. Angle 60–61deg and backward-facing wind are rejected. No smoothing at correlation boundaries. Apparent wind is horizontal. Effective misalignment satisfies cos(theta)=sin(phi)cos(yaw), so a vertical inlet has theta 90deg. Slow-air delta uses the horizontal-wind/vertical-settling vector dot product (zero), an explicit geometric generalization of the scalar coplanar source. Arbitrary vertical wind and experimental validation of 3-D correlations are not claimed. The original scalar delta=(v/U0)(v/U0+2*cos(theta+phi)) is correct only where those angles are coplanar.

Buffers have only residence time; a warning states that particle losses in them are unmodeled. Ideal well-mixed splits preserve concentration and track sensor/bypass particle-count fractions; no branch aspiration correlation is implied. Enlargements, blunt slots, shrouds, non-conductive electrostatics and thermophoresis have no implemented model.

Source conflict, aspiration.hangal_willeke (2026-11-15). W eq 7, re-read from the paper PDF, prints the Stokes exponent sqrt(U0/U) = sqrt(R), which the 0.1.0 candidate implemented. The implementation now uses sqrt(U/U0) = sqrt(1/R) and reports W_SOURCE_CONFLICT whenever the formula is used. Reasons: (1) at 90deg the bracket Rcos(theta)-1 equals -1, so R enters only through the exponent; with sqrt(R), aspiration of inertial particles rises as wind outruns the inlet velocity, the opposite of the inertial argument and of the experimental trend, in which right-angle aspiration falls with StR^(1/2) (Brixey, Evans & Vincent 2005, J. Aerosol Sci. 36:1144, https://stacks.cdc.gov/view/cdc/190534, summarizing the 1980s data); (2) as wind vanishes at fixed inlet flow (R and St to 0), St^sqrt(R) tends to 1 and A to -2, while St^sqrt(1/R) tends to 0 and A to 1, the calm-air limit; (3) sqrt(1/R) halves the summed 60/61deg boundary jump against Durham–Lundgren over St .02–.2, R .5–2 (1.87 to 0.89). The original article (Environ. Sci. Technol. 24:688) has not been checked; until it is, this is a physically argued deviation from the printed secondary source, not a confirmed correction. G0 item open.

Correction 2026-11-15, transmission.hangal_willeke_angle. W eq 17/18 print the wall-impaction parameter as Stksqrt(U0/U)sin(theta±alpha)sin((theta±alpha)/2). The 0.1.0 candidate computed sqrt(StkU0/U)*…, which for Stk<1 overstates Iw (by 1/sqrt(Stk), about 3x at Stk=.1) and therefore oblique-probe wall losses. Fixed to the printed form; the arithmetic fixture was regenerated.

Brockmann written notes SAND2010-7446P, https://www.osti.gov/servlets/purl/1675151, independently confirm the equations and give approximate bend guide points (St=.05/.16/.32, penetration about 1/.5/.1, adjacent curvature 8 geometry). These are checked at a predeclared absolute .06 tolerance and labeled approximate, not precision validation. Contraction uses the primary standard-reference factor 2, unlike W. Validity diagnostic x is defined using the same factor 2; the exact original validation interval remains a provenance gap.

Independent implementation review

Date: 2026-11-14. Reviewer: a separate agent that did not write the solver, bindings, worker, tests, or guides. This review covers implementation increments I0–I7; it is not practitioner acceptance or experimental validation.

Disposition

The project is a useful provisional software candidate with unusually explicit evidence limitations. It must not be described as an experimentally validated inlet designer or as having passed all of the plan's scientific gates. The current README, guides, result metadata and validation protocol make that distinction correctly.

The core equations and conventions were reviewed against the published Particle Loss Calculator paper and Brockmann's Sandia tutorial slides and written notes. No PLC program code was consulted. The original Allen–Raabe DOI was independently verified against its publisher. Most original empirical papers and precise published numerical anchors remain outstanding, as the formula registry states.

Findings corrected during review

  • The primary Brockmann contraction expression contains a factor of two relative to the printed PLC expression. The implementation keeps that source choice, upstream velocity/downstream diameter, and an explicit source-conflict diagnostic. The fitted coefficient 3.14 is retained as published; it is not replaced with pi.
  • Calm-air Stokes number uses inlet velocity, while moving-air aspiration uses freestream velocity. Bend angle uses radians internally and the selected standard-reference convention uses tube diameter.
  • A nonfinite general-chain CDF previously could produce a finite, false quantile through the bisection comparison. Quantiles now propagate the failure, and response preflight bounds reject expensive/stiff cases before solving.
  • Optimization now uses MODE for multiple objectives, propagates contraction diameters, checks cancellation before baseline/cold work, and drops points that cannot be cold-checked before termination.
  • Distance at 18 km/h is explicitly selectable instead of inadvertently imposing the same distance requirement at 25 km/h.
  • Probe tilt and yaw now use a vector dot product for effective horizontal-wind misalignment. A small stated endpoint tolerance avoids rejecting a nominal 60-degree angle solely because of floating-point roundoff.

The reconstructed PLC virtual system has a material unresolved mismatch: only two of six approximate anchors meet the predeclared two-percentage-point absolute tolerance. At 40 L/min, predicted losses around 2–3% differ from roughly 5–6% in the paper; at 150 L/min, about 5–6% differs from roughly 40%. The reviewer independently inspected the printed turbulent expression and its Reynolds exponent; no missing printed exponent was found. The standard-reference dimensionless-to-dimensional conversion agrees with the implementation. The original Lee–Gieseke full text was not available, and the final 10 mm section at 150 L/min also exceeds the reported Re<15600 fit range. The cause has not been established and must not be attributed solely to unspecified geometry or air state. All failed anchors remain evidence. No coefficient was adjusted to obtain agreement.

Accepted limitations and remaining gates

The full-distribution bicycle search is particularly sensitive to a genuine source-coverage issue: Liu transmission extrapolated below its fitted Stokes range can exceed one slightly. Evaluation preserves and diagnoses that result; design search rejects it. A failed strict search therefore cannot establish that the hardware goals are physically unattainable. PM bias, resolution and this extrapolation barrier must be reported separately. The guides do so.

The finite-search result retains the first 256 failed candidate rows and an omitted count, rather than retaining arbitrarily many failures in memory. The Pareto archive is also bounded. This is a documented departure from the plan's unrestricted failed-row retention; individual fixture verification retains every row.

G0 and G1 remain incomplete. The optional AeroSampleR runtime comparison and an external IGOR Pro run were not performed. Approximate published bend guidance and the partial virtual-inlet reconstruction cannot substitute for precise original numerical evidence. G2 has computed studies but still needs an aerosol practitioner's assessment. G3 requires actual on-bike measurements under a protocol fixed before opening the data. No release, optimality proof, physical infeasibility proof or experimental agreement is established by this review.

1. First evaluation

Build and run the commands in the README. examples/bicycle.json describes a defined thin-walled inlet, not the slot of a sensor housing. Its total flow is 2 L/min, sensor branch 0.282 L/min, tube 15 cm long, bend 90deg with 2cm radius, and buffer 20mL. Inputs remain SI in JSON: multiply L/min by 1/60000 for m3/s, milliliters by 1e-6 for m3.

Start with check. An error prevents evaluation: unknown fields, negative flow, a blunt wall, an unexplained diameter jump, backward-facing wind, the 60–61deg correlation gap, or transition tube flow without explicit permission. A warning permits a numerical result and states what is extrapolated or unmodeled.

evaluate returns one scenario per positive-weight Cartesian combination. Each scenario has an efficiency curve, element/mechanism breakdown, the distribution-dependent PM response and the modeled time response. size_statistics averages the declared scenario probabilities; it is not a climatological confidence interval. Inspect warnings before using any curve.

The assumed distribution and model limitations travel in the result. A good-looking PM10 average can result from cancellation of over-aspiration and transport loss; changing the coarse mode can remove that cancellation. Compare size-resolved curves, worst-case scenarios and multiple distributions before choosing hardware.

2. Cases, units and diagnostics

schema must equal inlet-craft.case/0.1. Nested unknown fields are rejected. particles takes exactly one nonempty aerodynamic_diameter_m or physical_diameter_m list. Density defaults to 1000kg/m3 and dynamic shape factor to 1. Aerodynamic input is converted to physical diameter by a slip-corrected implicit solve; density is not applied twice. Diffusion uses physical size. Shape factor is used as an effective drag/mobility factor, an assumption for non-spherical particles.

If there is no explicit split, the sensor samples the final stream. Flow fractions in results are relative to ambient concentration times total inlet flow; aspiration enrichment can make them larger than one. With downstream branch losses, branch plus bypass flux is reduced by the branch deposition.

Air is dry and ideal. The chosen Sutherland/kinetic mean-free-path convention differs slightly from the original Allen–Raabe fit; W_RANGE reports its Knudsen envelope. Coagulation, charge, wall temperature, evaporation, platform wakes, humidity and sensor optics are excluded. The independent-mechanism product assumes losses do not alter later deposition behavior.

E_TRANSITION covers Re 2000–4000 inclusively. options.extend_laminar_transition=true applies laminar equations with W_TRANSITION. This is an estimate, not a verified transition correlation. A source-provenance or omitted-process warning is different from a formula-range warning.

Warnings are grouped by code, element path, formula and quantity; minimum, maximum and occurrence counts cover both requested sizes and PM quadrature particles. warning_count counts groups; warning_event_count counts individual events and depends on quadrature size. W_REGIME_BOUNDARY reports empirical endpoint jumps as advisory information, including regimes not used by that scenario. The endpoint classification has a 1e-10deg floating-point tolerance; the true 60–61deg gap is never interpolated. W_NONPHYSICAL carries the offending efficiency and its formula. Efficiencies are never clipped; instead nonphysical_transport_excess (per size) and nonphysical_excess (per PM cut) state how much of a result rests on transport factors above one.

upward_sampling selects the source's upward-flow transmission branch; false is downward sampling/upward-facing aperture. The tilt field controls effective angle, while this branch flag records orientation convention. The Grinshpun calm fit covers an upward-facing aperture tilted 0–90deg; a downward-facing calm/slow aperture is outside this implementation's geometry. Arbitrary three-dimensional external wind is not supported.

3. Wind, PM mass and response

Positive headwind points toward the rider; crosswind is signed lateral wind. Apparent incoming horizontal components are (riding_speed+headwind,crosswind). Optional platform.wind_samples takes wind speed, direction from heading (0headwind, 90crosswind, 180tailwind), and weights, in place of component arrays. Speed weights combine independently with wind weights and are normalized; zero-weight conditions are skipped. No stochastic independence beyond what the user declares is inferred.

The probe's effective angle satisfies cos(theta)=sin(phi)*cos(yaw), with phi the tilt from vertical. Vertical probes therefore see 90deg horizontal flow. A horizontal forward-facing probe with a sufficiently strong tailwind sees>90deg and is rejected. The slow-air interpolation uses the orthogonality of vertical settling and horizontal freestream for its vector speed correction; this is a declared geometric extension of the scalar source. Auto uses zero wind→calm, positive wind up to 1.5m/s→slow, above 1.5→moving. Extension of the slow interpolation below.5m/s is explicitly diagnosed. No calm threshold hides a small nonzero wind.

Each size mode is a number lognormal in physical diameter. Supply number concentration, geometric mean physical diameter and geometric standard deviation; 1 denotes an exact monodisperse population. All modes share the case's density/shape. PM ratios compare integrated particle mass below ideal 2.5/10µm aerodynamic hard cuts with and without the modeled inlet. They do not include the optical response or actual cut curve of a commercial sensor. No assumed mode is a measurement of Aachen's aerosol.

Integration uses the mass-shifted normal in log diameter, truncated at the ideal aerodynamic cut; nine standard deviations cover numerical tails. The exact truncated mass normalizes each mode, and convergence is tested between 64 and 128 bins. The user can choose 16–256 bins. A zero ideal mass returns null efficiency rather than a division by zero. The result records bins and the distribution.

Travel through tubes/arcs/conical tapers is plug delay. Each buffer is an ideally stirred tank with tau=V/Q. sensor.response_time_s means first-order tau, nott90; convert a measured single-pole t90 by dividing by ln10. A trailing average has mean ageT/2 and varianceT²/12.

mean_age_s sums plug delay, tank/sensor time constants and half the averaging interval. Multiplying by riding speed gives mean_position_offset_m: the reading belongs to air encountered that distance earlier along the trajectory. Correcting GNSS should use trajectory history at the mean timestamp, not simply shift coordinates on a curved road.

Resolution here means speed times the modeled step's10–90% rise time. It is separate from mean offset. The exact repeated-two-tank response is tested; longer chains use bounded uniformization and the trailing average uses 128-point quadrature. More than 12 tanks or excessive stiffness/work estimate is rejected before an expensive solve. This numerical cap is not a physical limit of mixing tanks.

4. Design search

examples/bicycle-study.json defines bounded JSON-pointer variables for inlet diameter, total flow, tube length, bend radius and buffer volume. Varying probe diameter preserves its wall ratio and changes connected equal-diameter sections until a contraction. Varying contraction outlet diameter propagates the downstream diameter until the next contraction. Other input edits must remain geometrically consistent; invalid trials remain failed evaluations.

Scalar mode minimizes worst-case absolute PM10 relative bias across declared conditions, subject to the study constraints. Multi-objective mode uses fcmaes MODE, with objectives PM10 bias, distance resolution and total flow(L/min), and one aggregate nonnegative constraint violation. Both use ask/tell so solver evaluations cannot exceed the exact budget, including invalid candidates. Bounds, feasibility and objectives of returned candidates are re-evaluated cold; baseline and cold-check evaluations are separately reported outside the optimizer budget.

constraints.distance_reference_speed_m_s=5 evaluates the resolution constraint/objective at 18km/h as requested by the companion design. Without it, maximum resolution across all declared speeds is used. The candidate still reports the maximum across all speeds separately. Optional constraints bound PM10 relative bias, resolution, total flow, warning-group count and laminar Re. A negative extrapolated efficiency always rejects a candidate. A transport efficiency above one rejects it too, unless the study declares constraints.max_nonphysical_pm10_excess; then the candidate is accepted only if, in every scenario, the share of the PM10 ratio resting on such values (PmResult.nonphysical_excess, reported per candidate as nonphysical_pm10_excess) stays within that allowance.

Budgets specify evaluations, seed and wall time. Cancellation is cooperative between complete objective evaluations; cold checks also obey cancellation/deadline. A deadline can therefore prevent an otherwise promising point from being verified; it is then returned with cold_rechecked: false and the status does not count it as a feasible design. A recheck that fails is kept the same way, marked infeasible, with the error among its violations. The worker process can be killed by the job runner after its grace period. There is no solver checkpoint/resume claim.

feasible_design_found is conditional on the model and warning allowance. no_feasible_design_found means the finite search did not find an accepted design; it is not proof that none exists. Failed candidate rows are bounded to the first 256 in the compact result, with an explicit omitted count. Fixture verification keeps every row. The Pareto archive is bounded to 256 rechecked points and does not certify coverage of the true front.

The continuous fine-mode tail exposes a source limitation: Liu's small-Stokes transmission, extrapolated below its fitted range, returns values slightly above one for sub-micron particles in facing, sub-isokinetic scenarios. The evaluator reports these values without clipping and quantifies their weight: SizeResult.nonphysical_transport_excess is the overall efficiency minus the same product with every transport factor above one replaced by one, and the PM results integrate it over the mass distribution. In the bicycle study this weight is about 5e-4 of the PM10 mass. examples/bicycle-study.json therefore declares max_nonphysical_pm10_excess: 0.001, two orders below its 15% bias tolerance. Without that line every full-distribution candidate is rejected, which says nothing about hardware feasibility. Choose the allowance relative to your own bias tolerance, and do not use it to admit a large excess: that would mean the design depends on a correlation outside its fitted range.

See the generated bicycle study report, including a coarse-only sensitivity study and a deliberately impossible resolution constraint. They test search behavior under stated assumptions, not performance of a built sensor.

Build a native wheel using maturin build --release --locked, then install the resulting wheel from target/wheels/. The binding uses the same Rust parser and evaluator as the CLI and returns plain Python dictionaries. A JSON-coded ValueError carries Rust diagnostics. Python functions are check, evaluate, describe, verify, sweep, and optimize. The native functions exchange JSON internally; the Python sweep helper copies the input for each value and retains row failures. Evidence checks do not depend on Python assert statements and are repeated under python -O.

The anchors are confirmed by the paper text, not only read from the graph: case 2 (40 L/min) gives "at least 5%" for all sizes and case 3 (150 L/min) "at least 40% for all particle sizes". The flow regimes the paper names (case 2 laminar in sections 1 to 5 and turbulent in section 6; case 3 turbulent everywhere) match the computed Reynolds numbers. One geometry input is missing: Figure 7 labels the inlet "super-isokinetic sampling", which a 50 mm orifice cannot give at 10 to 150 L/min with U0 = 3 m/s. The program takes the orifice diameter as a separate input and the figure does not state it, so the transcribed 50 mm probe is an assumption. With the printed probe equations (eq 5 to 19, vena-contracta term extrapolated), an orifice small enough to make the 10 L/min case super-isokinetic adds under 4% loss at 0.1 to 0.3 µm and 150 L/min for orifices of 5 mm or more, and about 10% for a near-sonic 3 mm orifice; that term also grows with particle size instead of staying flat. This gap therefore does not explain the 40% plateau either.

Where the computed fine-particle loss comes from: at 40 and 150 L/min the largest share is the size-independent 2e-8*Re term of the Lee–Gieseke turbulent deposition velocity in the 10 mm tube, whose Reynolds number at 150 L/min (about 21000) lies above the fitted range. The published curve implies a loss that grows much faster with flow: between 40 and 150 L/min the computed log-loss scales as Q^0.61/0.73 (0.1/0.3 µm), the anchors imply Q^1.60/1.74; the size-independent term alone scales as Q^0.875 at fixed geometry. A mechanism with the published scaling is not among the implemented correlations, so the discrepancy is not a single-coefficient error that could be corrected here.

A failed anchor is evidence of an unresolved system/source discrepancy, not permission to fit a constant or copy PLC code. Potential omissions are named above, but are not demonstrated to explain a large discrepancy. The affected whole-system reproduction claim is withheld; the implementation remains a provisional literature-equation tool.
